# Frontend: Angular 22

Front de la solución de tipo de cambio. La documentación completa está en el [README principal](../README.md).

```bash
npm install
npm start                    # http://localhost:4200 (requiere la API en http://localhost:5062)
npx ng build                 # build de producción → dist/currency-exchange-web/browser
npx ng test --watch=false    # tests unitarios (Vitest)
```
